# Сайт психолога Маргариты Свитанько

Одностраничный сайт с админ-панелью. Работает только на стандартной
библиотеке Python — ничего устанавливать не нужно.

## Запуск

```bash
python server.py
```

- Сайт: http://localhost:3000
- Админ-панель: http://localhost:3000/admin
- Пароль по умолчанию: `admin123` — **смените его сразу** (вкладка «Смена пароля»).

Другой порт: `set PORT=8080 && python server.py` (Windows) или `PORT=8080 python server.py` (Linux).
Остановка: Ctrl+C.

## Что можно настроить в админ-панели

- **Основное** — имя, фразы, баннер, кнопки, главное фото (загрузка файла или URL).
- **Блоки сайта** — тумблерами включается и скрывается любой раздел:
  баннер, обо мне, фотографии, дипломы, направления, форматы и цены, контакты.
- **Обо мне и образование** — текст о подходе и об образовании.
- **Фотографии** — три фото с подписями (загрузка файлов с компьютера).
- **Дипломы** — отдельный блок: фото дипломов/сертификатов с названиями,
  количество любое.
- **Направления работы**, **Форматы и цены**, **Пакеты сессий** — списки
  с добавлением и удалением пунктов.
- **Контакты и соцсети** — Telegram, WhatsApp, ВКонтакте, Instagram,
  телефон, email. Не заполненные кнопки на сайте скрыты.
- **SEO** — Title, Description, Keywords, домен (canonical), картинка для соцсетей.
- **Смена пароля**.

Загрузка фото: кнопка «Загрузить» рядом с полем — файл уходит на сервер
(до 5 МБ, JPG/PNG/WebP/GIF, файлы лежат в `public/uploads/`), URL
подставляется автоматически. После этого нажмите «Сохранить изменения» —
и изменения сразу на сайте, перезапуск не нужен.

## SEO и Schema.org (уже настроено)

- Уникальные `title`, `description`, `keywords` из админки.
- Open Graph и Twitter Cards (картинка — из поля «Картинка для соцсетей» или фото).
- `canonical`, `robots.txt`, `sitemap.xml` (адрес берётся из поля «Домен сайта»;
  пока домен не указан — используется адрес текущего запроса).
- JSON-LD разметка Schema.org: тип **Psychologist** с ценами
  (OfferCatalog: консультация 4 500 ₽, семейная 5 000 ₽, пакеты из админки),
  фото, телефоном, email, городом, ссылками на соцсети (**sameAs**),
  а также **WebSite**. Проверить разметку: https://validator.schema.org/
  или «Проверка богатых результатов» Google.

Чтобы всё работало на боевом домене: в админке укажите домен в формате
`https://vash-site.ru` (без слэша на конце).

## Структура проекта

```
server.py          — сервер: страницы, API, загрузка фото, SEO-рендеринг
content.json       — всё содержимое сайта (редактируется админкой)
admin.json         — хеш пароля админки (создаётся автоматически)
public/
  uploads/         — загруженные фото (создаётся автоматически)
  index.html       — шаблон главной страницы
  admin.html       — админ-панель
  css/style.css    — стили сайта
  css/admin.css    — стили админки
  js/main.js       — меню, анимации появления
  js/admin.js      — логика админки
  favicon.svg      — иконка
```

## Примечания

- Тексты на странице подставляются на сервере из `content.json` — поисковики
  видят их без JavaScript.
- Загрузка файлов защищена: только авторизация, проверка сигнатуры картинки,
  лимит 5 МБ, имя файла генерируется сервером.
- Данные админки валидируются на сервере: сломать сайт через админку нельзя.
- Для постоянной работы на сервере оберните запуск в службу (systemd, планировщик
  задач Windows) и поставьте перед сайтом nginx/HTTPS.
