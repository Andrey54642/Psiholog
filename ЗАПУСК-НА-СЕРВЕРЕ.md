# Как запустить сайт на сервере

Понадобится любая машина с Python 3.9+ (на Windows, Linux/VPS — везде одинаково).
Зависимостей нет — копируете папку сайта и запускаете.

## 1. Локально (для проверки)

```bash
python server.py
```

- Сайт: http://localhost:3000
- Админка: http://localhost:3000/admin (пароль по умолчанию `admin123` — смените!).
- Другой порт: `set PORT=8080 && python server.py` (Windows) / `PORT=8080 python server.py` (Linux).

## 2. Windows (VPS или обычный компьютер)

1. Скопируйте папку проекта на сервер.
2. Запуск вручную: двойной клик по `start.bat` (или `python server.py`).
3. Автозапуск при перезагрузке — через Планировщик заданий:
   - Win+R → `taskschd.msc` → «Создать задачу».
   - Имя: `PsySite`, галочка «Выполнять с наивысшими правами» (не обязательно).
   - Триггер: «При запуске системы».
   - Действие: «Запуск программы» →
     программа: `C:\Users\<вы>\AppData\Local\Programs\Python\Python312\python.exe`
     (путь к вашему python; узнать: `where python`),
     аргументы: `server.py`,
     рабочая папка: полный путь к папке проекта.
4. Откройте порт 3000 в брандмауэре Windows
   (Панель управления → Брандмауэр → Правила для входящих → Создать правило → Порт → TCP 3000).
   Либо не открывайте и поставьте nginx перед сайтом (раздел 5).

## 3. Linux (VPS, например Ubuntu)

```bash
# 1) Копируем проект на сервер (с локальной машины)
scp -r psiholog user@ВАШ_IP:/home/user/psiholog

# 2) На сервере проверяем Python (обычно уже есть)
python3 --version

# 3) Служба автозапуска
sudo nano /etc/systemd/system/psysite.service
```

Вставьте (пути поправьте под себя):

```ini
[Unit]
Description=Site psiholog
After=network.target

[Service]
WorkingDirectory=/home/user/psiholog
ExecStart=/usr/bin/python3 /home/user/psiholog/server.py
Restart=always
RestartSec=5
Environment=PORT=3000

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable psysite --now   # запустить и включить автозапуск
sudo systemctl status psysite         # проверить
journalctl -u psysite -f              # смотреть логи
```

Открыть порт (если без nginx):

```bash
sudo ufw allow 3000/tcp
```

## 4. Домен

1. Купите домен и создайте у регистратора DNS-запись:
   тип `A`, имя `@` (или `www`), значение — IP сервера.
2. В админке сайта (вкладка «SEO») укажите домен: `https://vash-site.ru`
   (без слэша на конце). С этого момента `canonical`, `sitemap.xml` и
   Open Graph будут вести на ваш домен.

## 5. HTTPS — nginx + бесплатный сертификат (рекомендуется)

```bash
sudo apt install nginx certbot python3-certbot-nginx
```

`/etc/nginx/sites-available/psysite`:

```nginx
server {
    listen 80;
    server_name vash-site.ru www.vash-site.ru;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        client_max_body_size 6m;   # для загрузки фото (до 5 МБ)
    }
}
```

```bash
sudo ln -s /etc/nginx/sites-available/psysite /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx

# Сертификат (подставит HTTPS сам):
sudo certbot --nginx -d vash-site.ru -d www.vash-site.ru

# Автопродление проверить:
sudo certbot renew --dry-run
```

После этого сайт доступен по `https://vash-site.ru`, а порт 3000 снаружи
открывать не нужно.

## 6. Что бэкапить

Всё, что создаётся и меняется:
- `content.json` — весь текст сайта;
- `admin.json` — пароль админки;
- `public/uploads/` — загруженные фото.

Например, еженедельно копируйте папку к себе: `scp -r user@IP:psiholog ./backup`.

## 7. Проверка после запуска

1. Откройте сайт в браузере — все блоки на месте.
2. Войдите в админку, поменяйте текст, сохраните — обновите сайт: изменение видно.
3. Загрузите фото в админке — превью и сайт показывают файл.
4. Проверка SEO-разметки: https://validator.schema.org/ — вставьте адрес сайта.
5. Поисковикам сообщите: добавьте сайт в Яндекс.Вебмастер и Google Search Console
   (там же пришлите `https://vash-site.ru/sitemap.xml`).

## Частые проблемы

- **«Адрес уже используется»** — порт занят: другой запущенный сервер
  (`sudo systemctl stop psysite` или другой процесс) либо смените `PORT`.
- **Сайт работает локально, но не открывается снаружи** — закрыт порт
  в брандмауэре/ufw или VPS-биллинге (у многих хостеров есть веб-брандмауэр).
- **Фото не грузится через nginx** — проверьте `client_max_body_size`.
